# The Method

The Recursive Systems Method is built on three interconnected components:

## 1. Core Primitives

The fundamental building blocks that structure every investigation:

- **End State**: The desired outcome, held constant throughout the descent
- **Recursive Descent**: Systematic exploration of layers, each revealing new constraints
- **Evidence Ledger**: Rigorous separation of known, inferred, hypothesized, unknown, and disproved
- **System Map**: The evolving model of how things relate
- **Experiment**: Bounded tests that move hypotheses toward evidence
- **Tool Threshold**: The moment when problem structure matches a specialized capability
- **Handoff**: Transfer of work with complete state preservation
- **Synthesis**: Integration of findings back into the whole system

## 2. Agent Roles

Different intelligences (human, AI, specialized systems) serve different functions:

- **Explorer**: Descends through complexity, identifies boundaries, asks clarifying questions
- **Builder**: Transforms structured problems into artifacts, code, documentation
- **Critic**: Tests assumptions, identifies gaps, challenges premature conclusions
- **Validator**: Ensures decisions are grounded in evidence, catches drift
- **State Keeper**: Preserves context, authority, constraints, and intent across handoffs

No agent owns the end state. All agents serve it.

## 3. Operative Disciplines

How the method actually works in practice:

### Investigation Discipline
- Begin with what should be true
- Observe what is actually true
- Descend through the gap
- Separate evidence levels rigorously
- Let each discovery revise the map
- Never surrender the end state

### Tool Discipline
- Tool selection is itself an output of reasoning
- A tool is correct when the problem has become the right shape for it
- Tool choice occurs at a threshold, not at the beginning
- Handoff preserves everything the previous intelligence learned

### Orchestration Discipline
- Every agent knows what it is trying to achieve
- Every agent knows what constraints it operates within
- Every agent knows what it does and does not control
- State is explicit and inherited, not implied or lost
- Authority is clear: who decides what, and why

We modify the method itself.
